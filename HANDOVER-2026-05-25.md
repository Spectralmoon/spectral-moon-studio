## What we built today

### Contact section — split-screen redesign
The contact section is now a full split-screen: left 40% white/paper panel holds the contact text (dark espresso), right 60% dark espresso panel holds a crescent moon window with live fish footage.

The crescent is an SVG mask (no external images, pure geometry). Two video layers fill it:
- **Upper video** — `object-position: 60% 20%` pulls fish from the top of the footage into the upper crescent arc.
- **Lower video** — `object-position: 60% 80%` pulls fish from the bottom of the footage into the lower crescent arc.
- Both are synced via JS: `setInterval(resetSync, 4000)` resets both to `currentTime = 0` every 4 seconds simultaneously.
- A CSS gradient mask on the lower video (`to top, black 40%, transparent 75%`) blends the two layers seamlessly.

The crescent is rotated `-45°` around its own centre point using SVG `transform="rotate(-45, 1080, 450)"`.

### Sidebar navigation
- Font: **Anton** (bold, condensed) for Roman numerals.
- Color: **rose-deep** (`#C76A89`) on both the numeral and the section label — always on, not just active.
- Gap between items: `36px`.

### 2. Contact section video loop — try extending further if still busy
Current loop: 4000ms. If the reset still feels jarring, push to 6000ms in `script.js` line ~897.

### 3. Mobile review
The mobile SVG crescent (`contact-crescent-mask-mobile`) uses a smaller geometry and hasn't been tested since the `-45°` tilt and two-video approach were added. Test on iPhone viewport and adjust `object-position` values if fish aren't visible.

### 4. `doSnap` mobile guard (known issue #1 in CLAUDE.md)
`doSnap` fires on mobile and fights native touch scroll. Needs a `if (window.innerWidth <= 768) return;` guard at the top of the `doSnap` function in `script.js`.

### 5. Reveals ScrollTrigger mobile guard (known issue #2 in CLAUDE.md)
The reveals animation has no mobile guard — `end` calculation returns 0 on mobile. Needs the same `> 768` guard as the horizontal pin block.
